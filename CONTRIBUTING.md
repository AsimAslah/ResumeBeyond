# Contributing

ResumeBeyond accepts focused, evidence-based contributions.

## Workflow

1. Open a meaningful issue describing the user value, evidence, and acceptance criteria.
2. Create a `codex/` or descriptive feature branch.
3. Implement the smallest complete change.
4. Run `npm run check` and relevant browser tests.
5. Open a pull request with screenshots or measured evidence when presentation or behavior changes.
6. Resolve review findings, merge without force-pushing protected history, and close the issue.

## Claim policy

Candidate claims must be traceable to an approved public source in `docs/SOURCES.md`. Do not add performance numbers, employment claims, customer counts, deployment status, private contact details, or completion claims without evidence.

## Privacy policy

Never add chat logs, resumes containing private contact information, environment files, API keys, database contents, analytics identifiers, phone/WhatsApp links, residential locations, or unapproved email addresses.

## Commit style

Use conventional commits such as `feat: implement grounded virtual ambassador`, `fix: reject unsupported candidate claims`, or `test: add prompt-injection evaluation cases`.
